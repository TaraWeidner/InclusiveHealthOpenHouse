# Inclusive Health Open House Trivia

A mobile-first interactive trivia experience for Inclusive Health's October 1, 2026 Open House celebration.

## Current version

The first published version is an interactive visual tester. It includes:

- the player join screen
- the waiting room
- a sample trivia question
- answer selection and reveal states
- a sample live leaderboard
- host preview controls
- responsive phone and desktop layouts

The tester runs entirely in the browser. Separate phones are not synchronized yet.

## Next phase

The production version will add:

- the full Inclusive Health question bank
- separate player and host URLs
- live room codes and QR-code joining
- Firebase Realtime Database synchronization
- live scoring and response totals
- final rankings

## GitHub Pages

Deployment is handled by the workflow in `.github/workflows/pages.yml`.
